# Personal Website

Run locally
```
npm start   # or: task dev
```

Run `task` to list the [Taskfile](https://taskfile.dev) tasks (`dev`, `build`,
`preview`, `test`, `check:sources`, `audit`, `verify`). They wrap the npm
scripts in `package.json`.

## Deployment

The site is deployed automatically by GitHub Actions
(`.github/workflows/static.yml`) on every push to `main`. The Pages source is
set to "GitHub Actions" in repo settings.
