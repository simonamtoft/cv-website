## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The Talks page uses the card grid (WorkCardGrid) while Writing uses an editorial vertical list (.essays-list / .essay-item). The page should match Writing visually and let a visitor open a group in place to see its individual events. Agreed design: inline accordion on /talks (no new routes or modal); the closed row shows title and general description only; one-off events are plain rows linking out with no expand control. Follow the ui-design skill: a native disclosure button, visible focus, 44px targets, and reduced-motion-safe transitions.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Talks renders one row per group or one-off event, newest activity first, styled consistently with the Writing list
- [x] #2 Group rows start closed and open or close in place via a keyboard-operable control that exposes its expanded state to assistive technology
- [x] #3 An opened group lists its events newest-first, each with date, venue, short description, available metrics, and event or recording links
- [x] #4 One-off rows link directly to the event and show no expand control
- [x] #5 Event content is present in the prerendered /talks HTML, not only after JavaScript runs

- [x] #7 Desktop and 390px mobile screenshots show no layout breakage or horizontal scroll
