## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Talks are stored as flat entries in src/data/publicationsEvents.js, mixed with the op-ed articles that the Writing page reads. Grouping needs a structure in which a group (series or recurring conference) owns its general description and its events, and each event keeps its own date, link, recording, metrics, venue and original Danish title. Event descriptions currently run 2–3 sentences and repeat series context ("Fifth session in the Agentic Coding series..."). Once the group carries that context, each event only needs a short note on what was specific to it. Expected groups: Agentic Coding / Kod med AI (5 IDA AI webinars, 2026), Driving IT (2025, 2026), and Driving AI (2025, 2026). IDA Youth Summit 2026 stays a one-off. The agent drafts all copy and Simon reviews it, so do not invent facts beyond the existing descriptions and metrics.
