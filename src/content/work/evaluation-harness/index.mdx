## The problem

A team that ships ranking and suggestion features needs to know whether a change helps before users see it. Offline metrics are cheap to compute, but they are only useful when they move in the same direction as what users experience in the product.

## What I built

I led the design and build of a harness that tests ranking and suggestion strategies against historical data. Strategies are configured rather than hard-coded, so a traditional ML approach and an agentic generative-AI approach run through the same evaluation and can be compared directly.

The pre-launch metrics are aligned with real user experience, so they can gate a change before it reaches production.
