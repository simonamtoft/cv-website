## The problem

When data arrives from a new source, its attributes have to be matched to the attributes of the target model. The names rarely agree between sources, and matching them by hand is slow.

## What I built

I developed a semantic model, built on fine-tuned transformer embeddings, that identifies which attributes align across data sources. It recommends matches in real time, while the person doing the mapping is working.

## Result

The recommendations reduced manual mapping work and made onboarding faster.
