## The problem

The company wanted colleagues across the organisation to use agentic coding tools in their daily work.

## What I built

I created the company's Claude Code course. It teaches through video lessons and Q&A, and taking it also covers the company's compliance requirement for the tool.

I write about agentic coding in [Agentic Engineering](/writing/agentic-engineering).

## Result

The course is open to 2,000 consultants, and at least 600 have taken it.
